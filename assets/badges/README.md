# Badge Image Assets Directory

This directory contains badge and achievement visual assets for the **Google Cloud Arcade & Skills Achievement Portfolio**.

## Directory Structure

```text
assets/badges/
├── arcade-simulators/     # Arcade Simulator badges (e.g., Network Security Engineer)
├── arcade-adventures/     # Arcade Adventure interactive challenge badges
├── arcade-voyages/        # Arcade Voyage badges (e.g., Google Sheets)
├── arcade-trails/         # Arcade Trail & Re-Trail badges (e.g., Cloud Delivery Systems)
├── arcade-events/         # Arcade Base Camp, seasonal events, and Trivia milestones
├── skill-badges/          # Official Google Cloud assessment-based Skill Badges
└── other-achievements/    # Supporting technical learning and foundation credentials
```

## Attribution & Integrity

- **Source:** All badges and credentials correspond to public achievements hosted on [Google Cloud Skills Boost](https://www.skills.google/public_profiles/e1158899-3f93-4f1a-be6a-398d495945a0) and [Credly](https://www.credly.com/users/swapnil-patil.bbda7d25/badges/credly).
- **Authentication:** Badges link directly to verified public profile endpoints.
